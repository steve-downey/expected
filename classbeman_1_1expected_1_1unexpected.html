Detailed Description

template<class E>
class beman::expected::unexpected< E >

\mandates A program that instantiates the definition of unexpected for a non-object type other than an lvalue reference type, an array type, a specialization of unexpected, or a cv-qualified type is ill-formed.

Remarks
Subclause \iref{expected.unexpected} describes the class template unexpected that represents unexpected objects stored in expected objects.
