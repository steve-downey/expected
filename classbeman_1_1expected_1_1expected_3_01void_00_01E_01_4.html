Detailed Description

template<class E>
class beman::expected::expected< void, E >

\at expected.void.general \mandates A program that instantiates the definition of expected<T, E> with an E that is not a valid template argument for unexpected is ill-formed.

Remarks
Any object of type expected<T, E> either represents a value of type T, or contains a value of type E nested within it. Member has_val indicates whether the expected<T, E> object represents a value of type T. When has_value() is false, the error is unex.error().
